# moodle-logstore_opensearch

[![Documentation](https://github.com/moodle-observability/moodle-logstore_opensearch/actions/workflows/docs.yml/badge.svg)](https://github.com/moodle-observability/moodle-logstore_opensearch/actions/workflows/docs.yml)

Moodle log store that writes events to OpenSearch (`logstore_opensearch`). Log store (`tool_log` subplugin) that writes Moodle events to OpenSearch through `tool_opensearch`, in two independent modes, each in its own data stream.

**Status:** planning phase. There is no release yet.

Documentation (English and Brazilian Portuguese): https://moodle-observability.github.io/moodle-logstore_opensearch/

Requirements: Moodle 5.3 or later.

Part of [Moodle Observability](https://github.com/moodle-observability). Contributions: see the [contributing guide](https://github.com/moodle-observability/.github/blob/main/CONTRIBUTING.md).
